# 🏖️ Λέσβος · Παραλίες

Εφαρμογή Android (Ionic + Angular + Capacitor) για τουρίστες. Δείχνει όλες τις παραλίες της Λέσβου σε χάρτη
και, ανάλογα με τον άνεμο και τον προσανατολισμό κάθε παραλίας, εκτιμά αν θα έχει **ήρεμα νερά ή κύμα**.

## Τι κάνει

- **Χάρτης** με 42 παραλίες, χρωματισμένες ανάλογα με την κατάσταση της θάλασσας
  (🟢 ήρεμα · 🟡 λίγος κυματισμός · 🟠 κύμα · 🔴 μεγάλο κύμα). Το βελάκι σε κάθε παραλία δείχνει προς τα πού φυσάει.
- **Πρόταση «πού να πας»**: η πιο ήρεμη παραλία τώρα, και η πιο κοντινή αν δώσεις τη θέση σου.
- **Επιλογή ώρας**: σήμερα, αύριο και μεθαύριο, ανά ώρα, για να σχεδιάσεις τη μέρα σου.
- **Λίστα** με αναζήτηση, ταξινόμηση (πιο ήρεμες ή πιο κοντινές πρώτα) και φίλτρα:
  αγαπημένες, οργανωμένες, άμμος, για οικογένειες, ήσυχες, ταβέρνα, μάσκα, θερμές πηγές, γυμνισμός.
- **Σελίδα παραλίας** με πυξίδα (πού κοιτάει η παραλία και από πού έρχεται ο αέρας), πρόγνωση 24 ωρών,
  θερμοκρασία θάλασσας, ύψος κύματος στα ανοιχτά, περιγραφή και κουμπί οδηγιών στο Google Maps.
- **Προειδοποίηση για αέρα από τη στεριά**: τα νερά δείχνουν ήρεμα, αλλά τα φουσκωτά παρασύρονται στα ανοιχτά.
- **Συμβουλές**: ο κανόνας του αέρα, το μελτέμι, οι κόλποι, η κλίμακα Beaufort, θερμές πηγές και τοπικές γεύσεις.
- **Ελληνικά / English**, αγαπημένες παραλίες που αποθηκεύονται στη συσκευή.

## Πώς υπολογίζεται το κύμα

Κάθε παραλία έχει δύο τιμές στο `src/app/data/beaches.ts`:

- `facing`: προς ποια κατεύθυνση κοιτάει η παραλία, σε μοίρες (0 = Β, 90 = Α, 180 = Ν, 270 = Δ).
- `exposure`: πόσο ανοιχτή είναι στο πέλαγος (1 = ανοιχτό πέλαγος, 0.3 = κλειστός κόλπος).

Ο άνεμος (Open-Meteo, δωρεάν και χωρίς κλειδί) συγκρίνεται με το `facing`. Αν φυσάει από τη θάλασσα προς την ακτή,
δημιουργεί κύμα. Αν φυσάει από τη στεριά, τα νερά μένουν ήρεμα. Η λογική βρίσκεται στο `src/app/services/sea.ts`.

> Οι **συντεταγμένες** είναι τα επίσημα σημεία ελέγχου νερών κολύμβησης της Ευρωπαϊκής Υπηρεσίας Περιβάλλοντος (EEA).
> Ο **προσανατολισμός** (`facing`) και η **έκθεση** (`exposure`) είναι εκτιμήσεις και θέλουν έλεγχο επί τόπου.
> Τύπος ακτής και παροχές προέρχονται από τον οδηγό του lesvos.com· όπου δεν είναι γνωστά, μένουν κενά (`null`).

## Εκτέλεση

Χρειάζεσαι Node.js 20+ και Android Studio.

```bash
npm install
npm start                 # στον browser: http://localhost:4200
npm run android           # build + sync + άνοιγμα στο Android Studio
```

Στο Android Studio πατάς ▶ Run για να την τρέξεις σε emulator ή σε συσκευή.
Μετά από κάθε αλλαγή στον κώδικα τρέχεις `npm run sync`.

## Δομή

```
src/app/
  data/beaches.ts            δεδομένα παραλιών
  services/sea.ts            υπολογισμός κύματος, Beaufort, πυξίδα
  services/app-state.service.ts   καιρός, θέση, αγαπημένες, γλώσσα
  services/i18n.ts           κείμενα ΕΛ/EN
  pages/                     χάρτης, λίστα, παραλία, συμβουλές
  components/                επιλογή ώρας, σύνοψη παραλίας
android/                     project Android (Capacitor)
```

- Καιρός και θάλασσα: [Open-Meteo](https://open-meteo.com) (Forecast και Marine API)
