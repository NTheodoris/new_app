# 🏖️ LesvosGo

Εφαρμογή Android (Ionic + Angular + Capacitor) για τουρίστες. Δείχνει όλες τις παραλίες της Λέσβου σε χάρτη
και, ανάλογα με τον άνεμο και τον προσανατολισμό κάθε παραλίας, εκτιμά αν θα έχει **ήρεμα νερά ή κύμα**.

## Τι κάνει

- **Χάρτης** με 42 παραλίες, χρωματισμένες ανάλογα με την κατάσταση της θάλασσας
  (🟢 ήρεμα · 🟡 λίγος κυματισμός · 🟠 κύμα · 🔴 μεγάλο κύμα). Το βελάκι σε κάθε παραλία δείχνει προς τα πού φυσάει.
- **Πρόταση «πού να πας»**: η πιο ήρεμη παραλία τώρα, και η πιο κοντινή αν δώσεις τη θέση σου.
- **Επιλογή ώρας**: σήμερα, αύριο και μεθαύριο, ανά ώρα, για να σχεδιάσεις τη μέρα σου.
- **Λίστα** με αναζήτηση, ταξινόμηση (πιο ήρεμες ή πιο κοντινές πρώτα) και φίλτρα:
  αγαπημένες, οργανωμένες, άμμος, για οικογένειες, ήσυχες, ταβέρνα, μάσκα, θερμές πηγές, γυμνισμός.
- **Σελίδα παραλίας** με πυξίδα (πού κοιτάει η παραλία και από πού έρχεται ο αέρας), πρόγνωση 24 ωρών,
  θερμοκρασία θάλασσας, ύψος κύματος στα ανοιχτά, περιγραφή και κουμπί οδηγιών στο Google Maps.
- **Προειδοποίηση για αέρα από τη στεριά**: τα νερά δείχνουν ήρεμα, αλλά τα φουσκωτά παρασύρονται στα ανοιχτά.
- **Συμβουλές**: ο κανόνας του αέρα, το μελτέμι, οι κόλποι, η κλίμακα Beaufort, θερμές πηγές και τοπικές γεύσεις.
- **Ελληνικά / English**, αγαπημένες παραλίες που αποθηκεύονται στη συσκευή.

## Πώς υπολογίζεται το κύμα

Κάθε παραλία έχει δύο τιμές στο `data/beaches.json`:

- `facing`: προς ποια κατεύθυνση κοιτάει η παραλία, σε μοίρες (0 = Β, 90 = Α, 180 = Ν, 270 = Δ).
- `exposure`: πόσο ανοιχτή είναι στο πέλαγος (1 = ανοιχτό πέλαγος, 0.3 = κλειστός κόλπος).

Ο άνεμος (Open-Meteo, δωρεάν και χωρίς κλειδί) συγκρίνεται με το `facing`. Αν φυσάει από τη θάλασσα προς την ακτή,
δημιουργεί κύμα. Αν φυσάει από τη στεριά, τα νερά μένουν ήρεμα. Η λογική βρίσκεται στο `src/app/services/sea.ts`.

> Οι **συντεταγμένες** είναι τα επίσημα σημεία ελέγχου νερών κολύμβησης της Ευρωπαϊκής Υπηρεσίας Περιβάλλοντος (EEA).
> Ο **προσανατολισμός** (`facing`) και η **έκθεση** (`exposure`) είναι εκτιμήσεις και θέλουν έλεγχο επί τόπου.
> Τύπος ακτής και παροχές προέρχονται από τον οδηγό του lesvos.com· όπου δεν είναι γνωστά, μένουν κενά (`null`).

## Εκτέλεση

Χρειάζεσαι Node.js 20+ και Android Studio.

```bash
npm install
npm start                 # στον browser: http://localhost:4200
npm run android           # build + sync + άνοιγμα στο Android Studio
```

Στο Android Studio πατάς ▶ Run για να την τρέξεις σε emulator ή σε συσκευή.
Μετά από κάθε αλλαγή στον κώδικα τρέχεις `npm run sync`.

## Έκδοση web (για iPhone ή οποιονδήποτε browser)

👉 **https://ntheodoris.github.io/new_app/**

Ανοίγει την εφαρμογή σε οποιοδήποτε κινητό ή υπολογιστή, χωρίς εγκατάσταση. Στο iPhone: άνοιξε το link στο
Safari → κουμπί κοινοποίησης → **Προσθήκη στην οθόνη Αφετηρίας**, και θα έχεις εικονίδιο σαν κανονική εφαρμογή.

Για να ανέβει νέα έκδοση μετά από αλλαγές στον κώδικα: `npm run deploy:web`. Χτίζει την εφαρμογή και την ανεβάζει
στο branch `gh-pages`. Οι αλλαγές στις παραλίες (από τη σελίδα διαχείρισης) **δεν** το χρειάζονται.

## Backend: Firebase (Cloud Firestore)

Οι παραλίες ζουν σε βάση δεδομένων **Cloud Firestore** της Google, στο δωρεάν πλάνο **Spark**: χωρίς κάρτα,
δεν χρεώνει ποτέ. Τις διαχειρίζεσαι από τη **σελίδα διαχείρισης** της εφαρμογής, με σύνδεση Google:

👉 **https://ntheodoris.github.io/new_app/admin**

Εκεί μπορείς να:
- διορθώσεις οποιοδήποτε στοιχείο παραλίας
- **σύρεις τον δείκτη** στη σωστή θέση πάνω στον χάρτη
- **πατήσεις πάνω στη θάλασσα** μπροστά από την παραλία για να οριστεί προς τα πού κοιτάει (υπολογισμός κύματος)
- προσθέσεις νέα παραλία ή να κρύψεις μία
- κατεβάσεις αντίγραφο ασφαλείας σε JSON

Οι αλλαγές φτάνουν στους χρήστες στο **επόμενο άνοιγμα** της εφαρμογής, χωρίς νέα έκδοση.

**Ασφάλεια:** όλοι μπορούν να διαβάζουν τις παραλίες. Αλλαγές κάνει **μόνο** ο λογαριασμός Google που είναι γραμμένος
στους κανόνες του Firestore ([`firestore.rules`](firestore.rules)).

**Όρια δωρεάν πλάνου:** 50.000 αναγνώσεις/ημέρα. Η εφαρμογή διαβάζει **ένα** έγγραφο (τον αριθμό έκδοσης) σε κάθε άνοιγμα,
και κατεβάζει τις παραλίες μόνο όταν έχει γίνει αλλαγή. Χωράνε δηλαδή δεκάδες χιλιάδες ανοίγματα τη μέρα.

**Εφεδρεία:** αν το Firebase δεν απαντά, η εφαρμογή διαβάζει το `data/beaches.json` από το GitHub, μετά την τελευταία
λίστα που έχει στη συσκευή, και τέλος τα ενσωματωμένα δεδομένα. Στις «Συμβουλές», κάτω κάτω, φαίνεται η πηγή.

### Ρύθμιση (μία φορά, ~15 λεπτά)

1. **Project**: https://console.firebase.google.com → σύνδεση με το Gmail σου → **Create a project** →
   όνομα `lesvos-beaches` → Google Analytics: **όχι** → Create.
2. **Web app**: στην αρχική του project πάτα το εικονίδιο **`</>`** (Web) → όνομα `LesvosGo` →
   *χωρίς* Firebase Hosting → Register app. Θα εμφανιστεί ένα `firebaseConfig = { ... }`: **αντίγραψέ το**.
3. **Βάση**: μενού αριστερά **Build → Firestore Database** → **Create database** → Location **eur3 (Europe)**
   → **Start in production mode** → Create.
4. **Κανόνες**: στη Firestore Database → καρτέλα **Rules** → σβήσε ό,τι υπάρχει → επικόλλησε το
   [`firestore.rules`](firestore.rules) → άλλαξε το `ΤΟ_EMAIL_ΣΟΥ@gmail.com` στο Gmail σου → **Publish**.
5. **Σύνδεση Google**: **Build → Authentication → Get started** → **Google** → Enable → διάλεξε support email → Save.
   Μετά **Settings → Authorized domains → Add domain** → `ntheodoris.github.io` → Add.
6. **Config**: βάλε τις τιμές από το βήμα 2 στο `src/app/config.ts` (`apiKey`, `authDomain`, `projectId`, `appId`)
   και ξαναβγάλε την έκδοση web (`npm run deploy:web`).
7. **Εισαγωγή**: άνοιξε https://ntheodoris.github.io/new_app/admin → **Σύνδεση με Google** →
   **Εισαγωγή 42 παραλιών**. Τέλος. Στις «Συμβουλές» της εφαρμογής θα γράφει «ζωντανά από το backend (Firebase) ✓».

> Οι τιμές του `firebaseConfig` **δεν** είναι μυστικές: είναι φτιαγμένες για να μπαίνουν σε εφαρμογές.
> Την ασφάλεια την κάνουν οι κανόνες του βήματος 4.
>
> Η σελίδα διαχείρισης είναι για υπολογιστή ή κινητό μέσω browser. Μέσα στην εφαρμογή Android η σύνδεση Google δεν
> υποστηρίζεται, ούτε χρειάζεται.

## Εικονίδιο, οθόνη έναρξης και γραφικά για το Google Play

Τα τρία πρωτότυπα είναι στο `resources-src/originals/` (`icon.png`, `splash-bg.png`, `feature.png`).
Αν τα αλλάξεις:

```bash
npm run icons        # φτιάχνει όλα τα μεγέθη για Android, web και τα γραφικά του store
npm run sync
```

- Web: `public/icons/` και `public/manifest.webmanifest` (στο iPhone: Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας»).
- Google Play: `store/icon-512.png` και `store/feature-graphic-1024x500.png`.

## Δομή

```
src/app/
  config.ts                  σύνδεση με Firebase + εφεδρεία GitHub
  admin/admin.page.ts        σελίδα διαχείρισης παραλιών (/admin)
  services/firestore-rest.ts ελαφριά ανάγνωση από το Firestore (χωρίς SDK)
  data/beaches.ts            ενσωματώνει το data/beaches.json στην εφαρμογή
  services/beach-repository.service.ts   φόρτωση παραλιών: Firebase → GitHub → συσκευή → ενσωματωμένα
  services/sea.ts            υπολογισμός κύματος, Beaufort, πυξίδα
  services/app-state.service.ts   καιρός, θέση, αγαπημένες, γλώσσα
  services/i18n.ts           κείμενα ΕΛ/EN
  pages/                     χάρτης, λίστα, παραλία, συμβουλές
  components/                επιλογή ώρας, σύνοψη παραλίας
android/                     project Android (Capacitor)
data/beaches.json            αρχικά δεδομένα (εισαγωγή στη βάση) + εφεδρεία
firestore.rules              κανόνες ασφαλείας της βάσης
```
